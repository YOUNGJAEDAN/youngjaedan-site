# 회의 1 회의록 — 영재단 소개 페이지 (라운드 1 종합)

종합: 지우 · 2026-11-25 · 메모 3개(지우·예린·태오(Codex)), 서로 보지 않고 작성

## 합의 (세 메모 모두)

- **작은 정적 페이지 한 장**에서 시작한다. 로그인·문의 폼·가입·실시간 상태·AI 대화·내부 API 연결은 하지 않는다.
- **첫 방문자는 지인·개발자**(폰으로 링크를 여는 사람). 보고 나서 "이 팀이 어떻게 일하는지" 이해하고 **GitHub 조직(YOUNGJAEDAN)으로** 넘어가는 것이 목표.
- 직원을 누르면 **이름·역할·하는 일** 카드. **WebGL이 없어도** 같은 내용이 나온다.
- "근무 중" 같은 실시간처럼 보이는 표시와 지어낸 수치는 금지. "AI 직원"임을 분명히 적는다.
- 캐릭터 그림체는 살리되, 지금 캐릭터 페이지는 밝은 배경·영어 문구·WebGL2 필수·폰 글자 7px라 **화면 틀은 영재단 브랜드(다크, ✦)로 새로**.

## 이견

| 쟁점        | 지우                    | 예린                                    | 태오                                    |
| ----------- | ----------------------- | --------------------------------------- | --------------------------------------- |
| 3D 캐릭터   | 무거운 연출은 빼자      | 히어로로 쓰되 정지 이미지 먼저          | 선택해서 켜는 구경 요소, iPhone 30fps 실측 |
| 프로젝트 칸 | 판 1에는 없음           | 언급 없음                               | 확인 가능한 결과물 목록(없으면 "준비 중") |
| 호스팅      | —                       | —                                       | GitHub Pages 우선 검토(조건 미확인)     |

지우 의견: 첫 화면은 **캐릭터 정지 그림 + "3D로 보기" 버튼**이 세 의견의 교집합. 프로젝트 칸은 "만드는 중" 한 줄로 두고 실제 레포가 생기면 채운다.

## 확인한 사실

- 캐릭터 그림은 12명, 직원은 11명 — 12번째는 대표.
- GitHub 무료 조직은 GitHub Pages를 **공개 레포에서만** 쓸 수 있다(비공개 레포 + Pages는 유료). 비공개로 두려면 다른 무료 정적 호스팅(예: Cloudflare Pages)이 필요.

## 대표 결정이 필요한 것

1. 목적 — 명함·기록용(권장) / 개발자 커뮤니티 공유 / 협업 문의
2. 대표 본인 표시 — 넣되 ✦로 구분(권장) / 빼기
3. 3D — 정지 그림 + "3D로 보기"(권장) / 첫 화면부터 3D / 3D 없음
4. 공개 — 공개 레포 + GitHub Pages, 검색 노출 끔(권장) / 비공개 레포 + Cloudflare Pages
