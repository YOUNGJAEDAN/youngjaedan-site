## 태오 · 테크 리드 독립 메모

### 1. 한 줄 제안
‘팀을 운영하는 방식과 실제 결과물’을 보여 주는 정적 소개 페이지를 만들고, 3D 캐릭터는 선택해서 켜는 구경 요소로 둡니다.

### 2. 누가 보나 / 보고 나서 무엇을 하길 바라나
AI 팀 운영에 관심 있는 제작자·잠재 협업자가 대상입니다. 대표 1명과 AI 직원 11명의 구성을 이해하고, 공개 프로젝트의 GitHub로 이동하길 바랍니다. 문의 유도형이라면 연락 수단·개인정보 처리 범위를 추가로 정해야 합니다.

### 3. 꼭 되어야 하는 동작 3개
1. 직원 선택 → 이름·역할·협업 관계를 읽기. WebGL 없이도 가능합니다.
2. ‘3D 보기’ → 정면·3/4·뒤 전환. 실패하거나 느리면 정적 이미지로 돌아갑니다.
3. 프로젝트 선택 → 확인 가능한 저장소·결과물 열기. 공개 결과가 없으면 준비 중으로 표시합니다.

### 4. 일부러 안 할 것
로그인·실시간 근무 상태·AI 대화·내부 운영 API 연결은 제외합니다. 별도 레포 `YOUNGJAEDAN/youngjaedan-site`를 제안하며, 콘텐츠·스타일·WebGL 코드를 분리하고 간단한 정적 빌드와 CI로 배포합니다. 호스팅은 GitHub Pages를 우선 검토하되 요금·조건은 미확인입니다.

### 5. “됐다”의 기준
출시 목표: 390px에서 가로 넘침 없음, 키보드로 주요 동작 완료, WebGL 차단 시 소개·링크 정상 작동. 지정 iPhone Safari에서 3D 30fps 이상을 목표로 실측하고, 미달하면 기본 노출을 보류합니다. 현재 성능·운영비는 알 수 없음입니다.

### 6. 개발 관점의 위험·주의
원본은 WebGL2 필수이며 계속 렌더링합니다. 화면 밖·비활성 탭·동작 줄이기에서는 렌더를 멈춰야 합니다. 내부 앱 코드를 통째로 복사하면 유지보수가 갈라지므로 캐릭터 정의의 원본과 갱신 절차를 정합니다.

### 7. 대표에게 물을 질문
- 첫 행동은 프로젝트 탐색인가요, 문의인가요? **권장: 프로젝트 탐색.**
- 3D가 첫인상에 필수인가요? **권장: 정적 소개 먼저, 선택 실행.**
- 공개·갱신 책임자는 누구인가요? **권장: 대표 승인 후 실제 결과가 생길 때 갱신.**
