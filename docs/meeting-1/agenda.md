# 회의 1 — 영재단 소개 페이지 (아이디어 라운드 1)

소집: 대표 · 2026-11-25 · 유형: 아이디어 디벨롭(GENERAL)
참석: 지우(기획), 예린(프로덕트 디자이너), 태오(테크 리드)
규칙: 각자 **독립 메모 1개**(다른 사람 메모를 보지 않음). 지우가 종합. 대표가 코멘트하면 2라운드.

## 배경
- 영재단: 대표 1명이 이름 있는 AI 직원 팀(11명: 서연·수현·지우·예린·태오·도윤·이안·하린·건우·민재·유나)을 게임처럼 운영하는 1인 스튜디오.
  철학: "좋은 AI 모델을 많이 쓰는 회사가 아니라, 제한된 자원으로 좋은 팀을 구성하고 운영하는 회사." 진행·수치를 지어내지 않는다(정직 규칙).
- 앞으로 실제 프로젝트는 GitHub 조직 YOUNGJAEDAN 안의 레포로 만든다. 이 페이지가 첫 프로젝트 후보.
- 출발점: Codex가 그린 캐릭터 소개 페이지(WebGL, 12명 정면/3/4/뒤 보기, 내부 디자인 문서)
- 브랜드: 내부 브랜드 문서(다크 우선, 포인트 #D4B895, 별 ✦)
- 내부 도구 설명: 내부 자료(공개하지 않음)

## 안건
"영재단 소개 페이지"를 만든다면 — 누구에게 무엇을 보여 주고, 무엇을 하게 할 것인가?
대표는 아직 목적·대상을 정하지 않았다. 이 회의가 그 선택지를 만든다.

## 메모 형식 (한국어, 600~900자 안팎, 마크다운)
1. 한 줄 제안
2. 누가 보나 / 보고 나서 무엇을 하길 바라나
3. 꼭 되어야 하는 동작 3개
4. 일부러 안 할 것
5. "됐다"의 기준(측정 가능하게)
6. 내 역할 관점의 위험·주의 1~3개
7. 대표에게 물을 질문 최대 3개(각각 권장안 포함)

금지: 지어낸 수치·고객 수·성과. 모르면 "알 수 없음".
